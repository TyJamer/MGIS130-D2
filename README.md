# MGIS130-D2
D2 ideas and descriptions
data layer; my information would come from daily affirmations quotes
processing layer; the affirmations would be based off of the persons mood; anxious, confident, sad, happy, self-love. The usage of the quotes would not repeat until the full cycle of the quotes for that specific mood ran through. User mood check-ins based off of time of day. 
user interface; should look calming, light, peaceful colors, easy font to read and a decent size, images in the background to go with the quote. there would be buttons for the certain moods that a person feels, and when clicked on, an affirmation based off of it would appear. A heart, bookmark button to favorite affirmations. Keeping up socially, generating images based on the affirmation for sharing with others, custom quote creater button when you want to write one and affirm yourself.
